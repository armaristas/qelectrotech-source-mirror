# Fuentes de referencia

Copias de los programas locales del usuario para estudiar y portar sus reglas a QElectroTech. No forman parte de la compilación y no constituyen una integración funcional.

`manifest.json` registra la revisión base de QET y las huellas SHA-256 de los cinco scripts. `source_commit` es nulo porque no se pudo consultar el historial de los repositorios externos con los permisos de lectura disponibles. Las huellas corresponden al contenido local, incluidos posibles cambios sin commit.

El catálogo `Maker_Pro/catalog_marker.json` acompaña a la referencia de Marker. No se incluyen ejecutables, paquetes de distribución ni carpetas de compilación. Mantener las atribuciones originales y revisar licencias antes de distribuir estas referencias.

Las carpetas con las copias originales se conservan solo en este equipo y están excluidas de Git. El inventario y las huellas permiten identificar las versiones estudiadas sin incluir esos originales en las contribuciones del fork.
